# PDF Concurso EDU — Quiz de Pedagogia

Aplicação web para simulados randomizados de Pedagogia, acompanhamento de metas, indicadores de desempenho e relatório comentado.

## Executar

Projeto estático: abra `index.html` ou use qualquer servidor HTTP local.

## Publicação

Configuração pronta para Netlify em `netlify.toml`.
